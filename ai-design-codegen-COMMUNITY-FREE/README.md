---

## 🔧 How It Works

This app simulates AI-based design-to-code generation.

It:
- Analyzes uploaded project structure
- Detects keywords from image filename (dashboard, login, form, profile)
- Generates framework-specific structured UI code
- Adapts component naming based on existing project

---

## 🚀 Deploy on Streamlit Community Cloud

1. Upload this project to GitHub
2. Go to https://streamlit.io/cloud
3. Click "New App"
4. Select repo
5. Set main file as: app.py
6. Deploy

---

## 💻 Run Locally

pip install -r requirements.txt
streamlit run app.py
