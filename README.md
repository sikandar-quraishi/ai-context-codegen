# 🚀 AI Context-Aware Design to Code Generator (Full Demo)

## What This Project Does

✅ Upload existing frontend project (ZIP)
✅ Upload new Figma/UI screenshot
✅ Select framework (React / Vue / Angular)
✅ AI generates context-aware code
✅ Download generated component

---

## 🔧 Setup Instructions

1️⃣ Install dependencies

pip install -r requirements.txt

2️⃣ Create .env file

Copy .env.example to .env and add your OpenAI API key

3️⃣ Run the app

streamlit run app.py

---

## 🧪 Demo Steps

1. Upload the included sample_project.zip
2. Upload any UI screenshot
3. Select React
4. Click Generate
5. Download generated file
